## 操作逻辑调整

- 删除白名单 IP：保留确认弹窗，不收集、不发送 OTP。后端删除路由只保留管理员身份检查及审计日志。
- 新增白名单 IP：启用 2FA 的账号仍须有效验证码。
- 验证码回车：终端 Sudo、白名单新增、关闭 2FA、关闭 Sudo 保护、登录及远程执行输入使用 form 提交；已有启用 2FA、修改密码和终端 OTP 表单继续支持回车。提交过程中禁用按钮或阻止重复请求。
- 五种语言的白名单说明与 Docker README 同步更新。
